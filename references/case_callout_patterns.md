# 偏差 / OOS 案例挂接模式（关键点框写法）

把历史偏差处理报告、OOS-OOT 调查报告提炼后，挂进对应检验项操作卡的 🔴 关键点框，
是这份手册**最有价值**的部分——让操作人在现场直接看到别人踩过的坑。

---

## 一、数据外置（不要写死在卡里）

案例内容单独放一个数据模块（如 `deviation_cases_template.py`），字段：

```
code          报告编号（唯一键，card 通过它挂接）
kind          事件类型：偏差 / OOS-OOT
found         发现日期
item          对应手册检验项或环节（用于挂接卡内关键点）
grade         偏差/OOS 结论分级
phenomenon    现象描述
root_cause    根本原因（根源类别 + 溯源）
impact        造成的影响
decision      最终处理决定
capa          纠正与预防措施（CAPA）
keypoint      提炼出的「关键点 / 易错点」条目（挂到卡内 🔴 框，支持 **加粗**）
key_flag      卡内条目的编号前缀（接在原编号之后，如 ⑥；无则留空字符串）
```

另加 3 个**精简字段**（`phenomenon_s` / `root_cause_s` / `decision_s`）专供附录窄栏汇总表使用——
完整叙述太长，塞进表格会挤爆版面。

## 二、挂接方式（红框数量不变）

卡内关键点框的数量**必须等于检验项数量**，否则读者会以为是新增检验项。
做法：把案例关键点追加到既有 key_text 末尾，而非新增一个框。

```python
from deviation_cases_template import CASE_BY_CODE, attach_case
from docx_table_toolkit import add_key_callout

key_text = "常规要点①……②……"          # 卡原本的关键点
key_text = attach_case(key_text, "D-2026-008")   # 末尾追加 ⑥ △真实偏差…
add_key_callout(doc, key_text)         # 内含多个带圈序号 → 自动逐条分行
```

`attach_case` 把 `key_flag + keypoint` 拼到末尾；`key_flag` 为空（如纯背景类偏差）则原样返回。

## 三、卡内单条写法（固定句式）

```
<编号> △ 真实<类型> <报告编号>（<日期>）：<现象一句话>。<根因>。<可操作的规避要点>
```

最后一段必须是**读者下次能照做的动作**，不是复述调查过程。例如：

> ⑥ △ 真实偏差 D-2026-008（2026-09-04）：曾因把 SOP 要求的「移取 5ml 供试品」的 **5ml 移液管当成 2ml 移液管**使用，供试品与对照品同步稀释约 2.5 倍，主峰面积仅为预期的一半。移液管规格须与规定的移取体积逐条核对；主峰面积「整齐地」整体偏低约一半时，优先查移液管用错与稀释倍数，勿先怀疑仪器。

因 `add_key_callout` 按带圈数字逐条分行，编号 ①~⑥（含追加的案例 ⑥）会各自独立成行，扫读无障碍。

## 四、脱敏规则（合规底线）

偏差/OOS 报告含员工真实姓名，**内部传阅也必须脱敏**：

- 人名 → 岗位描述：`QC 主管 / 检测人员 / 新入职人员 / 取样人员 / 分析部经理`。
- 保留：编号、日期、批号、限度、仪器编号等可追溯信息。
- 结论以**签批 PDF** 为准（勾选项、签署链、手写补充结论）；电子版 DOCX 仅作技术内容主体。
- 数值照抄报告原文，不做换算或四舍五入。
- 例外：SOP/质量标准**封面审批栏**的签署人属于文档签署链（溯源信息），可保留。

## 五、共性归纳是这一节的灵魂

逐案罗列不如单列一节「共性规律」。4 起案例的共性往往是：

1. 根源类别都是「人员/行为」——文件里有明确要求、执行时被省略（移液管规格、转移完全与消泡、开启后立即配制、摆放方向）。
2. 异常都呈「整齐的系统性偏差」——峰面积整体减半、含量整体平行偏高、结果整体偏低、摆放方向整体颠倒。这类特征指向操作而非仪器，排查应先查配制与移取，再查仪器。
3. 复测都证明产品无问题，最终全部判为实验室出错、原始数据作废；异常数据不得直接放行，须按 OOS 流程复测并由 QA 批准后以复测数据为准。
4. CAPA 高度一致：重新配制 / 重新摆放 + 人员再培训；有效性以培训考核记录（如笔试合格签到表）为证，无签到表不算闭环。

## 六、附录配套

- 附录 B 扩写为「通用处理指引 + B.2 历史案例复盘（汇总表 + 逐案叙述）+ B.3 共性规律」。
- 附录 E 补人工复核提示：签批 PDF 与电子版 DOCX 的批号/勾选/签署差异、手写判读存疑处。
- 案例相关**人名在全文 0 残留**是验收硬指标（用全文文本搜索核对，注意 U+FFFC 伪影见避坑第 8 条）。
