# 骨化三醇注射液 v5→v6 修订实战复盘（品种专项）

> 本文是 `revision_playbook.md` 第一层通用规则在**一个真实品种**上的完整落地记录，
> 用来把抽象 SOP 变成可照抄的「实战样本」。
> 通用规则请回 `revision_playbook.md` §1~§10；本文只讲「这次怎么做的」与「映射到哪条规则」。
> 所有数值均为**本次实测**，标注「算例，非通用常量」的**禁止**写进脚本默认值（见文末红线）。

---

## 0. 项目性质与基线

- **性质**：Stage 6 修订 —— 一份**已经成稿的 v5 DOCX** 升到 v6，不是从零生成。
- **输入基线**：`8.骨化三醇注射液_全项检验准备与关键点控制手册_v5_20261111.docx`
  （历史成品，升版后**原样保留、不覆盖**，符合「v1~v5 成品不覆盖」惯例）。
- **输出**：`8.骨化三醇注射液_全项检验准备与关键点控制手册_v6_20261112.docx`
  （Z 盘，84,382 B）。**新文件名，不覆盖上一版。**
- **环境约束**：本机 Word COM 被沙箱拦截 → **只交付 DOCX**，PDF 由用户在 Word 手动导出
  （v5 有存量 PDF；v6 PDF 待用户导出后再补跑视觉级验收）。
- **已知债务（执行期禁碰）**：工作区生成脚本 `build_gsc_v5.py` / `data_gsc_v5.py`
  仍是 **v5 代号版**，重跑会回退到 v5 —— **禁止重跑**；本轮 v6 是「修订既有成稿」而非
  「重生成」，因此不依赖这些脚本。

## 2. 动作一 · 物料溯源补录（对应 §4 批号/供应商回填）

**数据来源**：12 份批检验记录扫描件（`JL-T-048-5003` / `JL-T-048-5004` 系列）。
本机无 tesseract，**视觉读取路径**：`pypdfium2` 250dpi 单页渲染 → `ViewImage` 视觉读取
（禁用 2×2 低清拼图、禁用 PyMuPDF）。定向读 5 类页：封面 / 目录 / 标准规定页 /
【变更历史】 / 【结论】。

**回填动作**：
- 在物料表 **F.2.1 / F.2.2 新增「供应商」列**（tblGrid 由 6 列变 7 列，列数对齐未动，仅加一列）。
- 逐份汇总所有批号并入「名称/规格/关键属性」列；加供应商。
- **对照品** → 中检院 / Sigma-Aldrich；**试剂** → 江苏北方联合 / 国药 / Adamas-beta / 安耐吉 等。
- 乙腈、甲醇来源手写多种写法（江苏北方联合 / 湖北邦农 / 迪马科技），疑批间差异 →
  **以主表为准并标「待核对」**，不擅自归一。
- 共 7 项留「需查」（来源多写法不一致或记录未载明）。

**分级口径守住了两条红线**（§4 核心）：
1. 方法学验证报告批号**未**充当对照品证书信息（来源不同不可互替）。
2. 批检验记录属实际执行记录，可逐份回填但**每条标来源文件+页码、留「待核对」**。

**品种现实（非通用规则）**：这 12 份记录目录模板一致，均**不含**细菌内毒素 / 无菌 / 热原项
→ 对应 `RP-08/09/10`、`RGT-13/14` 无来源可提，只能留「需查」。这是该品种当次的数据事实，
**不是**「所有品种都该留需查」。

## 3. 动作二 · 表格字体统一（对应 §3）

- 走 `patch_existing_manual.py --normalize-fonts --font-mode all-song`：
  全 run 后处理、`rPr/rFonts` 四属性（ascii/hAnsi/cs/eastAsia）齐全、`w:sz` 与 `w:szCs` 成对、
  空 run 跳过、Unicode 下标（MgSO₄/V₁）替换、窄列（<5cm、7pt）去加粗。
- **本次妥协**：成品采用「全宋体最小改动」（`all-song`），**未**在成品上验证
  中文宋体 + 英文 TNR 的分离版（`cjk-split`）。
- **已知 TODO**：下次生成/修订可改用 `--font-mode cjk-split` 并目视确认无重影/豆腐块。

## 4. 动作三 · 章节整合（对应 §5 + 品种级决定）

- **品种级决定**：把独立的「第 0 章 编制说明/溯源」**并入第 6 章**，原 `0.1~0.8`
  **重编号为 `6.5.1~6.5.8`**。`SKILL.md` Overview 里的「0) 编制说明/溯源」独立章节结构
  **不因此改动**——那是默认模板，不是本次品种结构。
- **技术动作**（§5）：
  - 标题**锚定定位**（表格搬移后 `doc.tables[i]` 会整体前移，一律按标题文本 + occurrence 消歧，
    不缓存表索引）。
  - 文本替换用 `set_para_text` / `replace_in` 保首 run 的 rPr（字体/字号/加粗不丢）。
  - 编号变更后**清点全文交叉引用**（目录、页眉、附录指向），防数值串误替换（如 `0.5μg` 被当章号）。
- **红线**：旧增量说明 6.5.5~6.5.8 与版本沿革表旧行**一律不改写**，只新增。

## 5. 动作四 · 矩阵可读化（对应 §6）

- 矩阵由 `build_matrix()` 自动派生，单元格 `完整名称（编号）`（如 `XX 对照品（RP-01）`），
  同类顿号 `、` 连接；列头 `中文全称（缩写）`（`MATRIX_CAT_HEADERS`）。
- **品种编号**：本次矩阵落在 **F.3**（因为附录 G 顺延成了 F）；其他品种可能是 G.4 或别号——
  不写死。
- **横向矩阵列宽实测（算例，非默认）**：`[1900, 2020, 2590, 1930, 3130, 3000]` tw，
  合计 `14570` tw = 25.70 cm，恰等于横向版心（`get_content_width` 按 pgSz@w 直接算得，
  **勿按 orient 再互换 w/h**）。

## 6. 动作五 · 矩阵精简（对应 §6 删列三同步）

- **品种级决定**：当次删掉「供试品与样品制备（SMP-）」列 —— 该列在骨化三醇里信息稀疏。
  删后矩阵为 **18 行 × 6 列**。
- **三同步**（删列必做，§6）：`tblW` 合计、`tblGrid/gridCol` 数量与宽度、每行每格 `tcW`
  一起改；表头 `tblHeader` 与数据行 `cantSplit` 保留。
- **红线**：六类物料数据模型与供试品分节表（`SMP-`）本身**完好保留**；技能模板**不删类**，
  删矩阵某列 ≠ 删物料表。

## 7. 动作六 · 零回归验收（对应 §8）

`verify_revision.py --config` 的**本次实战 config**（完整 JSON 见文末，可直接当模板复用）：

```
tables=76, paragraphs=248（v5 的 240 → v6 的 248，新增增量说明 8 段）,
callouts=17（= 卡片数）, matrix 18×6, sectPr=3（不变）,
其余 74 表逐格零改动
allowed_cells 白名单仅放：
  - 供应商列 7 格（「需查」/ 新填值，预期会变）
  - 封面/摘要/沿革表/增量说明 4 处「当前版本」字段（预期会变）
```

**文本级**：章节标题全命中、关键限度全命中、物料编号 0 缺失且六类前缀齐全、红框数=卡片数
（精确串 `● 关键点 / 易错点` 计数防目录假阳性）、U+FFFC 伪影 0、`**` 残留 0（段落+所有表格单元格一起扫）。

**零回归四联断言**（核心）：旧汇总数字/旧标题 0 命中 + 新增编号全命中 + 主依据限度全命中且
红框数=卡片数 + 附录行数联动（沿革表 +1 行、增量说明 +1 节）。

**OOXML 结构级**（本次主力，因无 PDF）：与 baseline 逐格比对，除 `allowed_cells` 外零改动；
`tblW`/`gridCol`/`tcW` 三者一致且 `tblLayout=fixed`；列宽合计 = 所在 section 版心
（容差：因逐列 `round()` 累计差几个 twips，断言按列数自适应，勿绝对相等）；
`w:br[type=page]`=0、`w:pBdr` 分隔段计数 = 卡数−1、`rFonts` 四属性与 sz/szCs 成对齐全。

**视觉级**：本机 COM 被拦截 → 整层标 `SKIP`，报告固定打印
「PDF 需用户在 Word 手动导出、逐页目视待补」。**未把结构级通过表述为版式已验收。**

## 8. 正式升版机制（对应 §9，本品种实测步骤）

1. **新文件名**：`…_v6_20261112.docx`，不覆盖 `…_v5_20261111.docx`。
2. **就地更新「当前版本」字段**（允许改）：
   - 封面副标题 / 版本栏 / 编制日期；
   - **共享页眉 part**：3 节共用同一 header part，按元素 id 去重，**改 1 处全生效**；
   - 封面摘要 para4（第 4 段概述）。
3. **克隆保格式新增**（不改写历史）：
   - 版本沿革表 `tbl1`：**克隆 v5 行** + 新增一行「v6 物料与附录整合」；
   - 新增「**6.5.9 v6 增量说明**」一节 = 标题段（1 run 加粗）+ 概述段（3 run）+ 6 条
     `List Bullet`（每条 2 run，加粗前缀），**克隆 6.5.8 模板段**保格式，勿 `doc.add_paragraph()` 裸建。
4. 旧增量说明 6.5.5~6.5.8 与沿革表旧行一律保留。
5. **收尾提醒**：每次改完文档后，最终回复必须主动提醒更新「版本名称」+「文件名中的日期」
   （列出文件名/封面/页眉/沿革表/增量说明的实际位置 + 当前值 + 建议值）；**提醒 ≠ 擅自改名**，
   升版号与是否新增增量说明由用户确认后再动。话术模板见 `revision_playbook.md` 附录 B。

## 10. 哪些是本品种决定、不得通用化（复述红线）

- F.3 是「附录 G 顺延为 F」后的品种编号；其他品种可能是 G.4 等。
- 删「供试品与样品制备（SMP-）」列是当次「矩阵精简」决策，六类物料模型与供试品表本身保留。
- 第 0 章并入第 6 章、`0.1~0.8 → 6.5.1~6.5.8` 是品种级结构决定，默认模板的「0) 独立章节」不动。
- 12 份批检验记录不含内毒素/无菌/热原项 → 对应物料留「需查」，非通用规则。
- **实测数字一律算例，严禁写进脚本默认值**：横向矩阵列宽 `[1900,2020,2590,1930,3130,3000]`tw
  合计 `14570`tw；矩阵 `18×6`；段落 `240→248`、表 `76` 不变、`3` 个 `sectPr` 不变、其余 `74` 表逐格零改动。
