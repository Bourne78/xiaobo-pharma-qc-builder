# 检验物料清单（备料核对清单）数据模型

附录 G 的物料清单用一份**单一数据源** `MATERIALS` 驱动六张分节表 + 一张 检验项×物料 矩阵。
核心原则：**矩阵由物料的 `items` 字段自动推导，绝不手写两份不同步的清单。**

## 1. 六类物料与编号前缀
| 类别 | 编号前缀 | 说明 |
|---|---|---|
| 对照品与工作对照品 | `RP-` | 含工作对照品（LK036-A/B/C） |
| 试剂、试液与标准溶液 | `RGT-` | 含配制类（"XX（配制）"） |
| 供试品与样品制备 | `SMP-` | 各规格 + 通用取样量 |
| 色谱柱与固定相 | `COL-` | 含固定相描述 |
| 仪器设备 | `INS-` | 含型号/资产编号/校准状态（现场回填） |
| 消耗品与器皿 | `CON-` | 滤膜/比色管/针头/量瓶等 |

## 2. 单条物料字段（dict）
```python
dict(
    id="RP-01", name="聚多卡醇对照品",
    spec=NEED, lot=NEED, expiry=NEED, storage=NEED,   # 规格/批号/效期/保存
    qty="约50mg/份（平行2份）",                       # 需求量
    use="系统适用性溶液、含量测定对照品溶液、鉴别(2)",  # 用途
    items=["3.2","3.7","3.8"],                         # 用于哪些手册卡号（驱动矩阵）
    src=SRC_SOP, src_ref="§3.3.3、§3.3.5、§4.3、§4.5", # 来源标记 + SOP 章节/页码
    prep="§3.3.5 系统适用性溶液：取聚多卡醇对照品约50mg……",  # SOP 原文（可独立成列，也可不渲染）
)
```
- `spec/lot/expiry/storage`：对照品**证书信息**（规格/批号/有效期/保存条件）在现行 SOP 中常未载明，填 `需查`。
  **方法学验证报告中的批号属验证用样品/试剂信息，不得当作对照品证书信息补入**（来源不同，不可互相替代）。
  但**批检验记录扫描件**属实际执行记录，可逐份汇总其中的实际批号与供应商回填 `lot` / `supplier`，
  每条须标注来源文件与页码并保留「待核对」标记；分级口径、台账与验收见
  `references/revision_playbook.md` §4。
- `supplier`（可选）：物料供应商。批检验记录回填时填写；来源多写法不一致时以主表为准并标「待核对」。
- `qty`：**凡 SOP 给出克数/毫升/浓度/支数/孔径的填确定值；仅给配制动作的填"按SOP配方"**。
- `prep` 字段逐字取自 SOP 原文，不改写数字；仅对 OCR 误识作正字（福尔马耕→福尔马肼、蛋白陈→蛋白胨、乙晴→乙腈、对昭品→对照品）。精简版手册可**不渲染此列**，只保留 `qty`/`spec` 等确定值。

## 3. 来源标记枚举（src）
| 常量 | 含义 |
|---|---|
| `SRC_SOP` = "SOP原文" | SOP 02 版明确载明 |
| `SRC_STD` = "质量标准(SOP未载)" | 质量标准载明、SOP 未载（须确认是否纳入 SOP 修订） |
| `SRC_CHECK` = "需查" | 现行 SOP 与质量标准均未载明 |
| `SRC_OUT` = "外包" | 外部单位开发验证并负责检测 |

统一占位 `NEED = "需查"`（SOP 未载时）。

## 4. △ 手册卡号 ≠ SOP 章节号（最容易取错物料的坑）
手册第 3 章的卡号与 SOP 的章节编号**并不一致**，核对物料前必须先换算：
```
SOP 实际编排：1 性状 → 2 鉴别 → 3 检查(3.1 pH、3.2 澄清度、3.3 有关物质、3.4 甲醛乙醛、
3.5 甲酸乙酸、3.6 乙醇、3.7 内毒素、3.8 无菌、3.9 可见异物、3.10 装量、3.11 微粒) → 4 含量测定
手册 3.5 可见异物 = SOP §3.9；手册 3.7 有关物质 = SOP §3.3；
手册 3.10 甲酸乙酸 = SOP §3.5；手册 3.14 内毒素 = SOP §3.7
```
→ 维护一张 `CARD_INFO`（卡号, 检验项, SOP章节号, SOP页码, 关键物料类别, 首次必齐项）用于换算。

## 5. 矩阵自动生成
```python
def build_matrix(cats=None, legacy=False):
    out = {}
    cats = MATRIX_CATS if cats is None else cats   # 类别可裁剪（少一列）
    for card in CARD_SOP_MAP:
        row = []
        for cat in cats:
            names = [f"{m['name']}（{m['id']}）" for m in MATERIALS[cat] if card in m["items"]]
            row.append("、".join(names) if names else "—")
        out[card] = row
    return out
```
列头用「中文全称（缩写）」（`MATRIX_CAT_HEADERS`）；默认输出「完整名称（编号）」+ 顿号，
`legacy=True` 回旧「名称 编号 + 换行」。裁剪列须同步 `tblW` / `gridCol` / `tcW`，
见 `references/revision_playbook.md` §6。

## 6. 副表（可删，按需）
- 外包项 `OUTSOURCED`：SOP §3.7/§3.8 的委托检测（如江苏华阳制药负责内毒素、无菌）。
- 需查清单 `CHECKLIST`：现行 SOP 与质量标准均未载明、须现场查证的事项。
- 首次开检前置条件 `PRECHECK`：版本收严限度落实、对照品证书、柱寿命、设备校准、外包委托单等。

## 7. 表格呈现要点
- 勾选列：空单元格 + 表头写「√」+ 列宽 ≥1.0cm + 垂直居中 + 行高 AT_LEAST 0.62cm。
- **不用 ☐/☑ 符号**（宋体字形覆盖不一致易出豆腐块）；**不用 w:sdt 内容控件**（WPS 打印行为不可控）。
- 六张 G.3.x 表列宽合计各恰好 17.00cm（纵向版心）。
- 删除 G.0/G.1/G.2/G.4/G.5/G.6/G.7 等辅助小节时，记得同时删掉 G.4 带来的 landscape `add_section` 切换，保持 section 数量一致。
